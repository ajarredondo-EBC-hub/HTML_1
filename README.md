# 🌐 HTML_1

¡Bienvenido a **HTML_1**! 🚀 Este repositorio está dedicado a explorar y practicar los fundamentos del desarrollo web.

Un espacio de trabajo ideal para dar los primeros pasos en la creación de páginas, entender la estructura básica y experimentar con el código frontend. 💻✨

## 🛠️ ¿Qué encontrarás aquí?
* 📄 **Estructura básica:** Configuración inicial de documentos HTML5.
* 📝 **Etiquetas fundamentales:** Uso de encabezados, párrafos, listas y enlaces.
* 🖼️ **Contenido multimedia:** Integración de imágenes y estructuración visual.

## 🚀 Estado del Proyecto
